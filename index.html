Consecuencia ecológica

Base científica

Este modelo educativo representa calentamiento, enfriamiento, mezcla por viento, respiración, fotosíntesis, sedimentación y liberación interna de nutrientes mediante relaciones simplificadas. No sustituye un modelo hidrodinámico ni mediciones de campo. Los colores del agua representan la variable seleccionada; el paisaje es ilustrativo.

Guía de exploración

Lee el lago por capas

Elige un escenario y ajusta los parámetros. Observa cómo cambian las capas, la termoclina y los perfiles de temperatura, oxígeno y nutrientes.

Selecciona una profundidad con un clic o un toque. Con el lago enfocado, usa ↑ y ↓ para recorrer sus capas, Inicio y Fin para ir a los extremos y Escape para cerrar la lectura.

Usa las pestañas para consultar la evolución, comparar tus cambios con las condiciones originales o entender sus efectos ecológicos. El modo guiado añade una orientación específica para cada escenario.

La tecla F amplía el lago. Puedes pausar, cambiar la velocidad o exportar el estado en JSON desde la cabecera.
