How to use

Read the lake like a limnologist

Use the scenario selector to start from a known condition, then modify climate, mixing, and water-quality controls. Watch how the colored layers, thermocline line, and depth profiles respond.

Hover over the lake to inspect each depth layer. The charts show how temperature, oxygen, and nutrients separate vertically. Alerts explain when the system approaches hypoxia, bloom risk, or turnover.

Switch to compare mode to see how your modifications diverge from the baseline scenario while keeping the same educational storyline.
